# Logo HSNCO pada website

Logo aktif: public/assets/images/logo-hsnco.png, sesuai file terbaru dari pemilik. Tulisan putih dan aksen emas sudah terdapat dalam sumber; tidak menggunakan pewarnaan ulang atau versi generatif.

AppServiceProvider menggunakan file ini untuk logo default header/footer dan mengganti referensi logo bawaan sebelumnya. Logo custom lain dari CMS tetap dihormati. Favicon HS putih berlatar hitam tetap menggunakan aset ikon terpisah.

Sumber PNG berbentuk persegi dengan ruang kosong di atas/bawah. CSS object-fit:cover dan object-position:center 58% membatasi tampilan ke area logo tanpa mengubah file asli. Header desktop menyediakan tinggi 100px, mobile 86px.

Versi logo-hsnco2-white.svg dari pekerjaan sebelumnya tidak lagi direferensikan oleh website. Tidak perlu mengubah database untuk mengganti logo default.
